# Make Fantasy Great Again

Best-ball league standings. One page, one password, nothing to click.

**Everything in this repository is encrypted.** `index.html` contains only
ciphertext — no names, no scores, no rosters are readable without the league
password. It is published here so the league has one permanent link; a hosting
provider holding these bytes learns nothing from them.

**Read-only by construction.** The page is a static file. There is no roster
editor, no trade button, no lineup form — not disabled, absent. Best ball needs
none of them: every team is scored on the mathematically optimal legal lineup
its roster could have produced, solved exactly, every week.

**Parody.** Not affiliated with, endorsed by, or representing any person,
campaign, party or government. The numbers are real; the commentary is a joke.

Generated by a private scoring engine that is not part of this repository.
